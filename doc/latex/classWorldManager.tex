\doxysubsection{Detailed Description}
\doxylink{classWorldManager}{World\+Manager} runs on dedicated generation worker threads. Responsibilities\+:
\begin{DoxyItemize}
\item Receives \doxylink{structChunkRequest}{Chunk\+Request} messages from the client
\item Generates/loads chunk data (procedural or from disk) on multiple worker threads
\item Pushes \doxylink{structGenerationTask}{Generation\+Task} to meshing threads
\item Manages chunk lifetime and caching
\item Tracks in-\/progress chunks to avoid duplicate work 
\end{DoxyItemize}
